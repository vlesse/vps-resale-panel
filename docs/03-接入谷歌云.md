# 第 3 章　接入谷歌云

这一章结束时，面板就能代表你去谷歌云建机器、开关机、重装、销毁了。

**你需要有一个谷歌账号**（就是平时登 Gmail 那个）。
如果还没开通谷歌云，第一次注册有免费额度，但**建实例需要绑定信用卡**。

**全程大概 20 分钟**，全部在谷歌云的网页控制台上点，不用敲命令。

---

## 3.1 先理解要做的是什么

面板需要一个「代表你去操作谷歌云」的身份。这个身份不是你的谷歌账号本身
（那太危险了，等于把你整个谷歌账号交出去），而是一个叫**服务账号**的东西 ——
你可以理解成「专门为这个程序开的一个小号，只给它建虚拟机的权限」。

这个小号的凭证是一个 **JSON 文件**，下载下来粘进面板就行。

整个流程是四步：

```
建项目  →  开 API  →  建服务账号并给权限  →  下载 JSON 密钥
```

---

## 3.2 建一个项目

谷歌云里所有资源都装在「项目」里。建议给面板单独开一个项目，
这样账单和配额跟你别的东西分开。

1. 打开 <https://console.cloud.google.com>，用你的谷歌账号登录
2. 点页面**最上方中间**那个项目选择器（显示当前项目名的下拉框）
3. 弹窗右上角点「**新建项目**」
4. 项目名随便填，比如 `vps-panel`
5. 点「创建」，等十几秒

创建好之后，**确认页面顶部的项目选择器显示的是你刚建的这个项目**。
后面每一步都必须在这个项目下操作，选错项目是最常见的错误。

### 记下项目 ID

项目 ID 和项目名**不是一回事**。项目 ID 通常是项目名后面加一串数字，
比如项目名叫 `vps-panel`，ID 可能是 `vps-panel-472913`。

在项目选择器弹窗里能看到「ID」那一列，**把它抄下来**，等下要填。

---

## 3.3 绑定结算账号

**没绑卡的话建不了实例**，谷歌云会直接拒绝。

1. 左上角三横线菜单 → 「**结算**」
2. 如果提示「此项目没有结算账号」，点「**关联结算账号**」
3. 没有结算账号的话点「创建结算账号」，按提示填信用卡信息

> 新账号一般有 300 美元的免费试用额度，但**免费试用期间也需要先绑卡**。

---

## 3.4 启用 Compute Engine API

新项目默认是不开虚拟机功能的，要手动打开。

1. 左上角菜单 → 「**API 和服务**」 → 「**库**」
2. 搜索框输入 `Compute Engine API`
3. 点搜索结果里的「Compute Engine API」
4. 点「**启用**」

**这一步要等两三分钟**，页面会显示「正在启用」。等它变成「管理」按钮就好了。

> 如果这一步跳过了，后面面板测试连接时会报：
> 「这个项目还没启用 Compute Engine API」。

---

## 3.5 建服务账号

1. 左上角菜单 → 「**IAM 和管理**」 → 「**服务账号**」
2. 顶部点「**+ 创建服务账号**」

**第一步「服务账号详情」：**

| 字段 | 填什么 |
|------|--------|
| 服务账号名称 | `panel` |
| 服务账号 ID | 会自动填成 `panel`，不用改 |
| 说明 | 随便填，比如「转售面板用」 |

点「**创建并继续**」。

**第二步「向此服务账号授予对项目的访问权限」** —— 这一步最关键。

点「选择角色」下拉框，在搜索框里输入 `Compute 实例管理员`
（英文界面是 `Compute Instance Admin`），选择：

> **Compute 实例管理员 (v1)**
> `roles/compute.instanceAdmin.v1`

⚠️ **一定要选带 `(v1)` 的那个**。列表里还有一个「Compute 实例管理员 (beta)」，
权限不完整，选错了建机会失败。

选好之后，**再点一次「+ 添加其他角色」**，加上第二个：

> **服务账号用户**
> `roles/iam.serviceAccountUser`

> 为什么要第二个？因为新建的虚拟机自己也会绑定一个服务账号，
> 没有这个权限的话谷歌云会拒绝创建，报 `Permission denied on service account`。

点「**继续**」，第三步不用填，直接点「**完成**」。

---

## 3.6 下载 JSON 密钥

1. 回到服务账号列表，**点你刚建的那个 `panel`**（点名字，不是点右边的三个点）
2. 上方标签页切到「**密钥**」
3. 点「**添加密钥**」 → 「**创建新密钥**」
4. 类型选 「**JSON**」
5. 点「创建」

浏览器会**自动下载一个 `.json` 文件**，文件名类似
`vps-panel-472913-a1b2c3d4e5f6.json`。

> ⚠️ **这个文件只能下载这一次**，关掉之后没法再下。
> 弄丢了只能回来再建一把新的（旧的记得删掉）。
>
> ⚠️ **这个文件等于你谷歌云的钥匙**，拿到它的人能在你账号上建机器花你的钱。
> 别发到群里、别提交到 GitHub、别贴在聊天软件里。

---

## 3.7 填进面板

1. 用管理员账号登录你的面板
2. 点「**后台**」 → 「**云账号**」
3. 点「**+ 谷歌云 Compute Engine**」

**账号备注名**：随便填，比如「谷歌云 主账号」，只是给你自己看的。

**项目 ID**：填 3.2 里抄下来的那串（比如 `vps-panel-472913`）。
留空的话系统会自动从 JSON 里读，一般也没问题。

**服务账号密钥（JSON 全文）**：
用**记事本**打开刚下载的那个 `.json` 文件
（Windows 右键 → 打开方式 → 记事本；Mac 用「文本编辑」），
按 `Ctrl+A` 全选、`Ctrl+C` 复制，粘贴到这个框里。

> ⚠️ **要从第一个 `{` 粘到最后一个 `}`，一个字符都不能少。**
> 不要用 Word 或者别的富文本编辑器打开它，那些软件会改动引号和换行，
> 改动过的密钥签名就对不上了，系统会提示「密钥签名校验没过」。

最后点「**添加并测试连接**」。

---

## 到这一步你应该看到什么

页面上出现绿色提示：

> **已添加，连接测试通过：连接成功**

云账号列表里出现一条记录，脱敏摘要显示：

```
项目：vps-panel-472913
服务账号：panel@vps-panel-472913.iam.gserviceaccount.com
```

---

## 报错对照表

面板在你点「添加」的时候会**真的去调一次谷歌云的接口**，所以填错了当场就知道。

| 提示 | 原因 | 怎么办 |
|------|------|--------|
| 谷歌云不认这份密钥 | 密钥被删了、粘贴少了几行、或者服务账号属于别的项目 | 重新下载一份 JSON 再填一遍 |
| 密钥签名校验没过 | JSON 内容被编辑器改动过（换行被吃掉） | 用记事本重新打开原始文件复制 |
| 这份 JSON 里没有 client_email 和 private_key | 下载的不是服务账号密钥，是别的 JSON | 回 3.6 重做，注意是「服务账号 → 密钥 → 添加密钥」 |
| 服务账号权限不够 | 3.5 第二步角色没选或者选错了 | 回 IAM 页面给它加上「Compute 实例管理员 (v1)」 |
| 这个项目还没启用 Compute Engine API | 3.4 跳过了 | 回去启用，等两三分钟 |
| 这个项目没有绑定结算账号 | 3.3 跳过了 | 去绑卡 |
| 缺少项目 ID | 项目 ID 那栏空着而且 JSON 里也没有 | 填上项目 ID |
| 服务器时间不对导致密钥被拒 | 服务器系统时间偏差超过 5 分钟 | 在服务器上执行 `timedatectl set-ntp true` |

## 建套餐时要填的参数（下一章会用）

到第 5 章建套餐的时候，谷歌云的套餐需要填这几个值。先了解一下：

| 参数 | 填什么 | 怎么查 |
|------|--------|--------|
| **可用区** | `asia-northeast1-a` | 见下表。注意结尾有字母 |
| **机型** | `e2-medium` | 见下表 |
| **系统镜像** | `projects/debian-cloud/global/images/family/debian-12` | 照抄即可 |
| **系统盘 GB** | `80` | 最小 10 |
| **磁盘类型** | `pd-balanced` | `pd-standard` 便宜 / `pd-ssd` 快 |
| **固定公网 IP** | **勾上** | 见下方说明 |

### 常用可用区

| 位置 | 可用区 |
|------|--------|
| 东京 | `asia-northeast1-a` |
| 大阪 | `asia-northeast2-a` |
| 首尔 | `asia-northeast3-a` |
| 台湾 | `asia-east1-b` |
| 香港 | `asia-east2-a` |
| 新加坡 | `asia-southeast1-a` |
| 美国俄勒冈 | `us-west1-a` |
| 美国洛杉矶 | `us-west2-a` |

### 常用机型

| 机型 | 配置 | 大致月成本 |
|------|------|-----------|
| `e2-micro` | 2 vCPU（共享）/ 1 GB | 约 $7 |
| `e2-small` | 2 vCPU（共享）/ 2 GB | 约 $14 |
| `e2-medium` | 2 vCPU（共享）/ 4 GB | 约 $27 |
| `e2-standard-2` | 2 vCPU（独享）/ 8 GB | 约 $50 |

> 价格随区域和汇率浮动，**上架前一定要去
> [谷歌云价格计算器](https://cloud.google.com/products/calculator) 算一遍**，
> 定价要高于成本。别忘了算上公网 IP 和出网流量的钱。

### 关于「固定公网 IP」

**强烈建议勾上。**

谷歌云没有「重装系统」这个 API，面板的重装实际做的是「删掉旧实例、
用同样参数建一个新的」。不勾这个选项的话，用户每重装一次 IP 就变一次 ——
这是转售最容易挨投诉的地方。

勾上之后系统会先占一个静态地址，重装时把它接回新实例，IP 保持不变。
静态地址是单独计费的（大约每月 $3），这笔钱要算进你的定价里。

面板在你建套餐时会**强制你确认这一项** —— 不勾的话必须显式声明
「我知道后果，就是不要固定 IP」。

---

## 定期看一眼账单

面板会在后台总览页显示「疑似还在计费的残留实例」，但那只覆盖面板知道的机器。
建议你**每周去谷歌云控制台看一眼**：

左上角菜单 → 「Compute Engine」 → 「虚拟机实例」

正常情况下，这里的机器数量应该和面板后台「机器」页里
`running` + `stopped` 的数量对得上。多出来的就是漏网的，直接删掉。

也可以设一个账单提醒：菜单 → 「结算」 → 「预算和提醒」，
设一个每月上限，超了发邮件给你。
