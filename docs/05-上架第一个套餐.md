# 第 5 章　上架第一个套餐

「套餐」就是你卖给用户的商品。这一章结束时，你的首页上会出现一个能下单的机型。

**大概 15 分钟。**

---

## 5.1 先算清楚成本

**这一步别跳过。** 定价低于成本的话，卖得越多亏得越多，
而且「下单即开」是自动的，等你发现的时候已经亏了一堆。

以谷歌云东京 `e2-medium`（2 vCPU / 4 GB）为例，一个月的成本大致是：

| 项目 | 大约 |
|------|------|
| 实例本身 | $27 |
| 80 GB pd-balanced 磁盘 | $8 |
| 静态公网 IP | $3 |
| 出网流量（按 200 GB 估） | $24 |
| **合计** | **约 $62 ≈ ¥450** |

> 流量是最容易被低估的一块。谷歌云出网到中国大陆约 $0.12/GB，
> 用户跑满的话这一项能超过实例本身。**上架前一定要去
> [价格计算器](https://cloud.google.com/products/calculator) 按你的实际配置算一遍。**

所以这个配置卖 ¥45 是**巨亏**的。要么定价 ¥500 以上，
要么换更便宜的配置（比如 `e2-small` + 20 GB 磁盘）。

**AWS Lightsail 好算得多**，因为是固定价含流量：
`small_3_0` 是 $12/月含 3 TB 流量，卖 ¥120 就有得赚。
**刚开始做建议先用 Lightsail**，成本可控。

## 5.2 建套餐

后台 → 「**套餐**」 → 「**+ 新建套餐**」

### 基本信息

| 字段 | 填什么 | 说明 |
|------|--------|------|
| 套餐名 | `新加坡 2C2G` | 用户看得到 |
| 标识 slug | `sg-2c2g` | 英文小写，全站唯一，之后不要改 |
| 机房显示名 | `新加坡 · 亚洲东南` | 用户看得到 |
| 履约方式 | 下单即开 | 见下 |
| 平台 | AWS Lightsail | |
| 用哪个云账号 | 选你第 4 章加的那个 | |

> ⚠️ **「机房显示名」里不要写「AWS」「谷歌云」这些字。**
> 你从哪进的货是你的商业机密，用户只需要知道机器在新加坡。
> 面板的前台接口刻意不返回任何云厂商标识，你自己别在这里泄露了。

### 履约方式怎么选

| | 下单即开 | 库存池 |
|---|---------|-------|
| 什么时候建机器 | 用户付款后现建 | 你提前建好放着 |
| 支持的平台 | 谷歌云、Lightsail | 自有机器（SSH）、Proxmox |
| 交付速度 | 约 60–90 秒 | 立刻 |
| 成本 | 卖出去才花钱 | 空着也在花钱 |

**谷歌云和 Lightsail 选「下单即开」**，这是它们的优势 —— 没卖出去就不花钱。

自己手上已经有的机器走「库存池」，见 [第 7 章](07-卖自己的机器.md)。

### 规格和价格

| 字段 | 填什么 |
|------|--------|
| CPU 核数 | `2` |
| 内存 MB | `2048`（2 GB = 2048） |
| 磁盘 GB | `60` |
| 月流量 GB | `3000`（3 TB = 3000），可留空 |
| 月价（人民币） | `120` |
| 月价（美元） | `19`，可留空 |

> 这里填的规格**只是给用户看的展示信息**，真正决定机器多大的是下面的建机参数。
> 两边要对上，不然用户买的是 2 GB 结果拿到 0.5 GB，就要退款了。

### 建机参数

选了「下单即开」之后会出现这一段，字段随平台不同。

**AWS Lightsail：**

| 字段 | 填什么 |
|------|--------|
| 可用区 | `ap-southeast-1a` ← 结尾要带字母 |
| 套餐规格 | `small_3_0` |
| 系统镜像 | `debian_12` |
| 固定公网 IP | **勾上** |

**谷歌云：**

| 字段 | 填什么 |
|------|--------|
| 可用区 | `asia-northeast1-a` |
| 机型 | `e2-small` |
| 系统镜像 | `projects/debian-cloud/global/images/family/debian-12` |
| 系统盘 GB | `40` |
| 磁盘类型 | `pd-balanced` |
| 固定公网 IP | **勾上** |

### 卖点

一行一条，会显示在商品卡上：

```
独立公网 IPv4
BBR 已开启
SSH 直连 root
控制台可自助重装
```

最后点「**创建套餐**」。

## 到这一步你应该看到什么

**1. 套餐列表里出现了它**，右边显示：

```
¥120/月    已上架    付款后约 60 秒交付
```

**2. 前台首页能看到它**

打开 `https://panel.你的域名.com`，商品列表里有这个机型，
右下角写着「● 付款后约 60 秒交付」，「立即开通」按钮是亮的。

## 创建被拒绝了？

面板会在你点「创建」的时候检查配置，**能在这一步拦住的错误绝不会留到用户付款后** ——
用户付了钱才发现套餐配错了，就得退款。

| 提示 | 意思 | 怎么办 |
|------|------|--------|
| 「下单即开」的套餐必须绑定一个云账号 | 没选云账号 | 选一个。列表是空的说明第 3/4 章没做完 |
| xxx 驱动没法自己创建机器 | 平台选了「自有机器」但履约选了「下单即开」 | 履约改成「库存池」，或平台改成谷歌云/Lightsail |
| 套餐驱动是 lightsail，但绑的是 gcp 的账号 | 平台和账号对不上 | 换一个匹配的账号 |
| 还缺这些建机参数：xxx | 建机参数没填全 | 补上 |
| 可用区写错了：ap-southeast-1 | 少了结尾字母 | 改成 `ap-southeast-1a` |
| 标识 xxx 已经被别的套餐用了 | slug 重复 | 换一个 |
| **这个套餐没开「固定公网 IP」** | 见下 | 见下 |

### 关于最后那条

这不是配置错误，是**故意拦你一下**。

不开固定 IP 的话，用户每次重装系统 IP 都会变（因为重装的真实做法是
「删了重建」）。这是转售最容易挨投诉的地方，所以面板要求你显式确认。

确实不想开（比如你的用户不在乎 IP 变），
把「固定公网 IP」那个勾**取消掉再提交一次**就能过 —— 系统会记录你的选择。

## 5.3 自己走一遍下单流程

**上架之后一定要自己买一次。** 这是唯一能确认整条链路真的通了的办法。

但先别急 —— 你还没配收款方式，用户点了「立即开通」之后没法付钱。
所以顺序是：

1. 先做 [第 6 章 配置收款](06-配置收款.md)
2. 然后用一个测试账号下单
3. 用后台的「标记已付」跳过真实付款
4. 看着机器被建出来

第 6 章末尾有完整的演练步骤。

---

## 5.4 上架之后的调整

**改价格**：套餐页面暂时只支持重建来改价。改价对已经买了的用户没有影响，
他们续费时按新价格算。

**临时下架**：点「下架」。已经卖出去的机器不受影响，只是首页上看不到了、
新用户买不了。**想停止销售就用下架，不要删除。**

**删除**：只有从来没被下过单的套餐才能真删。有历史订单的会自动变成下架
（订单记录要能查回来）。还有用户在用的机器的套餐会直接拒绝删除。
