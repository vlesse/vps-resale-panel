# 第 1 章　你需要准备什么

这一章结束时，你会有一台能上网的服务器和一个指向它的域名。
面板还没装，那是下一章的事。

**这一章不需要任何技术基础。** 如果你从来没租过服务器，照着做就行。

---

## 1.1 先搞清楚三样东西是什么

在开始之前，先花两分钟弄明白这三个词，后面到处都会用到。

**服务器**　就是一台一直开着、一直连着网的电脑，放在机房里。
你租一台，每月给钱，就能远程用它。你的网站要跑在上面。

**域名**　就是网址，比如 `panel.example.com`。
你租一个，每年给钱。没有域名的话用户只能记一串数字（IP 地址），
而且没有域名就申请不了 HTTPS 证书，浏览器会给你的网站标上「不安全」。

**SSH**　一种远程操作服务器的方式。你在自己电脑上打开一个黑框框（终端），
输入一条命令，就能像坐在那台服务器前面一样操作它。
你后面会用它，但只需要复制粘贴几条命令，不用真的学。

---

## 1.2 租一台服务器

### 要多大的？

面板本身不吃资源，但 MySQL 数据库需要一点内存。推荐配置：

| | 最低 | 推荐 |
|---|---|---|
| 内存 | 2 GB | 4 GB |
| CPU | 1 核 | 2 核 |
| 硬盘 | 20 GB | 40 GB |
| 系统 | **Ubuntu 22.04 或 24.04** | 同左 |

> ⚠️ **系统一定要选 Ubuntu**（22.04 或 24.04 都行）。
> 别选 CentOS、Debian、Windows 或者别的 —— 本文档的所有命令都是按 Ubuntu 写的，
> 换系统命令就对不上了。

1 GB 内存的机器**也能跑**，但 MySQL 会很吃力，建议至少 2 GB。

> ⚠️ **内存不到 4 GB 的话，第 2 章有一步必须做**：加一块交换空间。
> 安装时要在服务器上编译前端代码，那一步吃 1 到 2 GB 内存，
> 不加交换空间会编译到一半被系统杀掉，而报错信息完全看不出是内存问题。
> 第 2 章开头的 2.0 节讲怎么加，一分钟。

### 在哪租？

随便哪家都行，只要是 Ubuntu 就可以。常见的几家：

- 国外：Vultr、DigitalOcean、Linode、Hetzner、CloudCone
- 国内：阿里云、腾讯云（**注意：国内服务器必须给域名备案，否则 80/443 端口用不了**）

**如果你是第一次做，建议先用国外的**，不用备案，当天就能跑起来。

### 租完之后你会拿到什么

租完之后，服务商会给你三样东西，记下来（后面要用）：

```
IP 地址：203.0.113.45          ← 一串用点分开的数字
用户名：root
密码：xxxxxxxxxxxx            ← 或者是一个密钥文件
```

有的服务商是让你自己设密码，有的是发邮件给你。找不到的话在服务商后台
「实例详情」或「Root Password」附近找。

## 1.3 买一个域名

在哪买都行：阿里云、腾讯云、Namecheap、Cloudflare、GoDaddy 都可以。
一年几十块钱。

买完之后你需要**做一条解析记录**，把域名指向你刚才那台服务器的 IP。

### 怎么做解析

到你买域名那家的控制台，找「域名解析」或者「DNS」，添加一条记录：

| 字段 | 填什么 | 说明 |
|------|--------|------|
| 记录类型 | `A` | 固定选 A |
| 主机记录 / 名称 | `panel` | 这样最终网址就是 `panel.你的域名.com` |
| 记录值 / 指向 | `203.0.113.45` | 换成你服务器的真实 IP |
| TTL | 默认就行 | 不用管 |

> **想直接用主域名（比如 `example.com` 不带前缀）？**
> 「主机记录」那一栏填 `@` 就行。

### 验证解析生效了没有

在**你自己电脑上**打开终端（Windows 按 Win+R，输入 `cmd` 回车），输入：

```bash
nslookup panel.你的域名.com
```

看到的结果里如果有你服务器的 IP，就成了。

如果显示「找不到」或者 IP 不对，等 10 分钟再试 —— DNS 生效需要时间，
有时候要等半小时。**这一步没成功就不要往下走**，
因为 HTTPS 证书是靠域名解析验证的，解析不对证书就申请不下来。

## 1.4 连上你的服务器

现在试着连一次，确认你能进去。

### Windows

Windows 10 以后自带了。按 Win+R，输入 `powershell` 回车，然后输入：

```bash
ssh root@203.0.113.45
```

（把 IP 换成你自己的）

第一次连会问：

```
The authenticity of host '...' can't be established.
Are you sure you want to continue connecting (yes/no)?
```

输入 `yes` 回车。然后它会让你输密码。

> **输密码的时候屏幕上什么都不显示，这是正常的**，不是键盘坏了。
> 直接把密码打完（或者粘贴进去）按回车。
> 粘贴的话在 PowerShell 里用鼠标右键，Ctrl+V 有时候不管用。

### Mac / Linux

打开「终端」，命令一样：

```bash
ssh root@203.0.113.45
```

### 连上之后应该看到什么

```
Welcome to Ubuntu 24.04.1 LTS (GNU/Linux 6.8.0-51-generic x86_64)
...
root@your-server:~#
```

最后那行 `root@your-server:~#` 就是命令提示符，
**看到它就说明你已经在服务器里面了**，之后所有命令都在这里输。

### 连不上？

| 现象 | 原因和解决办法 |
|------|--------------|
| `Connection refused` | 服务器还没启动完，等两分钟；或者服务商把 SSH 端口改了，去后台看 |
| `Connection timed out` | IP 抄错了，或者服务商的防火墙没放行 22 端口，去后台的「安全组 / 防火墙」里放行 |
| `Permission denied` | 密码错了。注意有些服务商初始密码里有容易看错的字符（大写 O 和数字 0） |
| `ssh: command not found` | 你的 Windows 太老了，去装一个 [PuTTY](https://www.putty.org/) |

## 1.5 做两件安全上的事

**这两件事不做也能跑，但强烈建议做。** 服务器一旦上公网，几分钟之内
就会有人开始扫描它试密码，这是常态，不是针对你。

### 改掉弱密码

如果服务商给的初始密码很短，换一个：

```bash
passwd
```

它会让你输两遍新密码。同样，**输的时候屏幕上不显示**。

### 打一遍系统更新

```bash
apt update && apt upgrade -y
```

这条要跑几分钟。中间如果弹出蓝色的窗口问你什么，一路按回车用默认值就行。

跑完如果它说要重启：

```bash
reboot
```

服务器会断开连接，等一分钟再用上面的 `ssh` 命令连回去。

## 到这一步你应该看到什么

三条都对上了才进下一章：

**1. 域名解析对了**

在你自己电脑上：

```bash
nslookup panel.你的域名.com
```

结果里有你服务器的 IP。

**2. 能连进服务器**

```bash
ssh root@你的IP
```

看到 `root@xxx:~#` 提示符。

**3. 系统是 Ubuntu**

在服务器里输：

```bash
cat /etc/os-release | head -2
```

应该看到：

```
PRETTY_NAME="Ubuntu 24.04.1 LTS"
NAME="Ubuntu"
```

（22.04 也可以）
